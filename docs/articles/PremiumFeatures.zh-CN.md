# 高级功能

## 传统 Il2Cpp 恢复

这是一个用于恢复 Il2Cpp 编译代码的实验性功能。它采用传统的反编译思路。可以在设置中选择脚本内容级别 3 来启用它。

出于性能考虑，`mscorlib` 以及所有名称以 `System` 或 `Unity` 开头的程序集都会被排除在分析之外。这些程序集的源代码通常应该能以某种形式公开获取。

从粗略观察来看，目前在 x86 游戏上，方法恢复成功率大约在 10% 到 20% 之间。其他平台的恢复率更低。相关改进仍在持续进行中。

## 着色器反编译

这是一个实验性的着色器反编译器，目标是支持所有变体并尽可能完整保留语义。不过它还没有打磨完善，因此在提取某些着色器时可能会抛出错误，导入 Unity Editor 后也可能出现编译错误。请在 [GitHub](https://github.com/AssetRipper/AssetRipper/issues) 上报告遇到的问题。

**平台支持：**

* Vulkan 着色器可以在任意平台上反编译。
* DirectX 着色器只能在 Windows 计算机上反编译。

## 静态网格分离

场景中被标记为静态的对象会在游戏构建时被合并。这是 Unity 用来减少绘制调用的一种优化。不幸的是，这也会让游戏资源恢复变得更加困难。此功能会尽最大能力逆转这一过程。

* 如果某个网格在游戏中被多次静态使用，即使跨越不同场景，AssetRipper 也会智能识别这些重复项，并为所有实例生成一个共享网格。
* 如果游戏文件中存在原始网格，则会优先使用原始网格，而不是生成新的网格。
* 静态批处理会丢失网格名称，因此会改用 GameObject 名称，并进行一些合理的名称清理。

此功能提供了一个启用设置，默认值为 true。

## 预制体识别

游戏构建时，场景中的所有预制体都会被内联，也就是实例化，因此原始预制体的信息会丢失。此功能会尝试分析游戏中的所有 GameObject 层级结构，找出可以替换为新的或已有预制体的重复结构，从而尽量逆转这一过程。

此功能提供了一个启用设置，默认值为 false。

## 资源去重

在构建多个资源包时，Unity 经常会重复包含多个资源包之间共享的资源。这样可以让每个资源包保持自包含。资源去重是一个实验性功能，用于逆转这一过程。

有些资源比其他资源更容易去重。目前此功能仅限于：

* Mono 脚本
* 着色器
* 计算着色器
* 音频剪辑
* 文本资源
* 网格
* 不带精灵的纹理

此功能提供了一个启用设置，默认值为 false。

## 用户定义包导出

对用户来说，包导出一直是最令人头疼的问题之一。以前，导出的项目只会引用 Unity 默认的一组核心模块。每当用户引用游戏曾经使用过的包时，新包就会与导出项目中的程序集和脚本发生冲突。删除这些冲突的导出文件又会破坏指向这些文件的资源引用。

有一些第三方工具可以帮助修复损坏的脚本引用，但它们大多依赖于根据 MonoBehaviour 字段进行猜测。此外，它们也不会修复其他资源类型的损坏引用。此功能的目的就是导出资源和包引用，让用户后续不必手动修复损坏引用。

不过，即使范围限制在 Unity 官方提供的包内，挖掘所有可能的包信息也并不可行。因此，用户和社区需要负责挖掘特定游戏所需的包信息。这里有一些资源可以帮助程序员完成所需的数据挖掘工作：https://github.com/AssetRipper/MarrowMiningDemo

这个实验性功能可以通过配置文件页面启用，该页面可从文件菜单中的 View/Configuration Files 进入。要启用此功能，用户必须上传适合目标游戏的包数据 json 文件。上面链接的 Marrow Mining Demo 中提供了示例 json 文件。

## 资源路径覆盖

此功能允许用户修改资源的导出目标路径。它可以通过配置文件页面启用，该页面可从文件菜单中的 View/Configuration Files 进入。要启用此功能，用户必须上传适合目标游戏的 json 文件。

### 路径覆盖文件结构

路径覆盖可以通过 json 文件提供。

```json
{
	"Files": {
		"cab-bcaf22789432bda1e5d0eea9d2521ddd": {
			"4476349470337976665": "Assets/AssetRenamed.txt"
		},
		"level1.assets":
		{
			"1": "Assets/Prefabs/Prefab1.prefab",
			"2": "Assets/Prefabs/Prefab2.prefab",
			"3": "Assets/Prefabs/Subfolder/SpecialPrefab.prefab",
			"12": "Assets/Images/MyTexture.png"
		}
	}
}
```

`Files` 是一个字典，键为表示资源集合名称的字符串。它的值也是字典，使用资源路径 id 作为键，使用新的输出路径作为值。路径相对于项目根目录。
